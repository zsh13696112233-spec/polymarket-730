# 单执行钱包、多目标实盘自动跟单说明

## 目标与边界

- 系统保留一个“我的钱包”作为唯一执行钱包，可选择任意一个已观察钱包作为跟单目标。
- 每个观察钱包保存一份独立实盘策略配置，多个钱包可以同时开启，共用一个执行钱包。
- 信号来自普通持仓监控生成的稳定事件，不读取、推测或复制目标钱包未成交挂单。
- 每次开启都以当前事件建立基线，不补关闭期间的历史开仓；意外重启会继续处理尚未完成的事件。

## 仓位与风控

- 买入目标金额 = 目标钱包首次建仓成交额 × 可配置比例，默认 10%。
- 每个市场周期单仓上限默认 $20；每个观察钱包的固定额度默认 $160。
- 每日买入与每日已实现亏损熔断默认分别为 $80、$40，按 Asia/Shanghai 自然日统计。
- 全局可用资本取 `min(执行账户总敞口, min(预算, 实时余额) - 现金保留额)`。
- 运行中钱包预留完整固定额度；已关闭钱包只按实际归因持仓占用额度。每日买入和亏损限制按所有钱包合计。

## 加仓、减仓和订单

- `opened` 按比例买入一次；`increased`、`decreased` 只记录；`closed` 卖出全部归因仓位；`redeemed` 自动赎回一次。
- 系统只卖出自动跟单归因仓位，不处理执行钱包上的其他持仓。
- 买卖均以检测时的当前盘口为基准，使用可配置的对称保护范围，默认 ±5¢、允许 0–50¢。
- BUY 按 USDC 金额、SELL 按份额提交 FAK；可成交部分立即成交，剩余取消，不重挂、不追单。
- 订单、成交、公开信号、归因成本、盈亏和拒绝原因全部落本地账本；成交指纹防止重复下单。

## 状态

- `active`：跟买、跟卖、自动赎回。
- `paused`：开启过程中的短暂内部状态。
- `exit_only`：用户关闭实盘开关；停止新买，继续跟随清仓和自动赎回。
- `closing`：撤单并清算全部归因持仓，完成后转为 `disabled`。
- `error`：凭证、余额或交易适配器出现不可安全继续的错误，停止新动作并等待人工恢复。

## 实盘与演练

- 自动跟单只提供实盘模式，使用 Polymarket 官方 V2 CLOB 客户端创建 FAK 市价单。
- 每次开启必须明确确认，并重新验证钥匙串私钥、V2 Exchange 授权、真实余额和固定额度。
- Dashboard 按当前买一价保守估算归因持仓的可卖出市值、浮动盈亏与总盈亏，并可查看已清仓和已赎回记录。
- `$5` 单边演练是真实下单，但不会归入自动跟单仓位。
- 实盘私钥与 Builder 凭证只保存在 macOS Keychain；数据库仅保存 service/account 引用。
- EOA 赎回直接提交 Polygon 交易；Proxy/Safe 通过官方 Builder Relayer 自动赎回。所有赎回必须拿到交易哈希才记为完成。

## 非目标

- 不保证跟随目标钱包后盈利。
- 不复制挂单、撤单意图、跨钱包资金调拨或目标钱包的非温度仓位。
- V1 不允许在执行钱包上混入手工交易；如需手工持仓，应使用另一个钱包。

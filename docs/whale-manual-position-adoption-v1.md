# 巨鲸跟单手动仓位归集 v1

巨鲸跟单使用执行钱包的统一 outcome 仓位口径。同一 asset 存在活动跟单周期时，
Polymarket 网页或其他客户端产生的手动买入、卖出会自动归集到该周期。

## 归集规则

- 首次跟单前 24 小时内仍影响当前余额的同 asset 手动买入可被归集。
- 跟单周期内的同 asset 手动买入增加份额和加权成本。
- 手动卖出按统一仓位比例结转成本，并计入已实现盈亏。
- 系统成交以 `whale_fills` 和订单账本中的交易哈希排除，避免再次作为手动成交入账。
- 外部事件使用唯一指纹幂等入账；重复扫描不会重复计算。
- 每轮归集后使用链上 ERC-1155 余额校验。官方成交数据尚未补齐时保留本地状态并产生扫描告警。
- 手动卖出后，剩余价值不超过 0.50 USDC 的仓位写入 `dust_writeoff` 并关闭。
- 自动赎回在手动成交归集之后运行，因此会赎回同 condition 下已归因的完整钱包余额。

## 流水来源

`whale_follow_ledger.source` 保留资金来源：

- `follow`：系统跟单买入或卖出；
- `manual`：Polymarket 外部手动买入或卖出；
- `auto_redeem`：系统自动赎回；
- `reconciliation`：链上对账及尾差核销。

页面的历史流水和逐仓时间线同时展示来源与操作类型。
